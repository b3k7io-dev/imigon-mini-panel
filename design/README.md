# Дизайн мини-панели

Этот файл описывает, за что отвечает каждый визуальный слой. Другой ИИ может улучшать дизайн, меняя только эти части.

## Файлы

- `index.html` — структура: шапка, поиск, чипы, сетка, toast.
- `styles.css` — основной визуальный слой, токены, анимации, responsive.
- `app.js` — состояние и рендер; классы карточек и кнопок задаются здесь.
- `config.js` — локальный ключ API для режима `file://`.
- `.env` — ключ API для локального HTTP-сервера.

## Токены

В `:root`:

- `--glass-bg` — основной полупрозрачный фон панели.
- `--glass-border` — тонкая граница стекла.
- `--glass-highlight` — внутренний блик.
- `--shadow` — мягкая тень панели.
- `--accent` — RGB-градиент для фокуса, активного чипа и кнопки копирования.
- `--radius-panel` — радиус панели.
- `--radius-card` — радиус карточек.
- `--ease-spring` — пружинная кривая анимаций.

## Основные блоки

- `.backdrop` — затемнённый и размытый фон; `pointer-events: none`, чтобы панель оставалась основной интерактивной поверхностью.
- `.panel` — плавающее окно. Размер, стекло, тень, анимация входа.
- `.panel::before` — верхний блик и цветовые отблески.
- `.panel::after` — внутренняя рамка и глубина, liquid-glass эффект.
- `.panel-header` — область перетаскивания.
- `.search-wrap` — pill-поиск; фокус подсвечивается градиентом `--accent`.
- `.chip` — фильтры; `.chip.is-active` использует градиент.
- `.image-card` — карточка изображения; stagger-анимация задаётся в `app.js`.
- `.copy-btn` — кнопка копирования; градиент и ripple.
- `.toast` — нижнее уведомление.
- `.skeleton-card` — shimmer-загрузка.

## Анимации

- Вход панели: scale + opacity с `--ease-spring`.
- Карточки: `card-in` со stagger через `animation-delay`.
- Кнопки: scale при `:active`, ripple через `.ripple::after`.
- Reduced motion отключает анимации в `@media (prefers-reduced-motion: reduce)`.

## Как улучшать

- Для более сильного liquid glass можно добавить SVG-фильтр `feDisplacementMap` и применить его к фону.
- Для Material You можно вычислять accent-цвет из доминирующего цвета изображения.
- Не делайте панель full-screen: сохраняйте `max-height: 70vh` и ширину около 340-400px.
- Все интерактивные элементы должны иметь минимум 44px.
- Проверяйте контраст текста на стеклянном фоне.
